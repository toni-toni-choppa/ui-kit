## Overview

This UI Kit provides reusable React components for building forms and documentation-style layouts.

Currently available public components:

- `Button`
- `Article`
- `Input` (`Text`, `Select`, `TextArea`, `Checkbox`, `Radio`, `Range`)

---

## Installation

Install the package with your preferred package manager.

### Requirements

- React 18+
- A bundler that supports CSS modules (Vite, Next.js, CRA, etc.)

### Install

```bash
npm install @toni-toni-choppa/ui-kit
```

---

## Basic Usage

```tsx
import { Button, Input } from "@toni-toni-choppa/ui-kit";

export default function Example() {
  return (
    <div>
      <Input.Text id="name" placeholder="Your name" />
      <Button label="Submit" onClick={() => alert("submitted")} />
    </div>
  );
}
```

---

## Component Docs

- Start with the `Input` module for all form controls.
- Use `Button` for primary and secondary actions.
- Use `Article` to structure long-form content sections.
